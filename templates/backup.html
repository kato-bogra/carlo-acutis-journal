Comment activer le Disque Persistant sur Render (Solution Définitive)

Pour que le serveur conserve vos écritures pour toujours sans que la secrétaire n'ait rien à réimporter.

1
Passer l'instance en Starter

Sur Render, allez dans votre service web carlo-acutis-journal > Settings > changez le plan en Starter (7$/mois). Cela empêche le serveur de se mettre en veille la nuit.

2
Ajouter un Disque Persistant

Dans l'onglet Disks de votre service Render, cliquez sur Add Disk :

  • • Name : journal-data
  • • Mount Path : /data
  • • Size : 1 GB
3
Variable d'environnement

Dans l'onglet Environment, vérifiez ou ajoutez :

DB_PATH = /data/journal.db

L'application détecte aussi automatiquement /data.
